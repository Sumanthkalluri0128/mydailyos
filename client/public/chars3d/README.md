FlexFit 3D character model assets
=================================

The app now renders articulated procedural 3D avatars, rather than sticker images.
For the final character-specific look, place licensed/authorized GLB 2.0 files here:

- luffy.glb
- naruto.glb
- asta.glb
- gojo.glb
- zoro.glb
- jinwoo.glb

Each GLB should be optimized for real-time use, include a humanoid skeleton, and have
animation clips with recognizable names such as Idle, Walk, Run, Jump, Climb, Attack,
Victory, PushUp and Squat. The web loader will use a GLB when available; if absent,
it keeps the procedural 3D avatar visible. Only use models you have permission to use.
