# Required 3D models

Place six properly rigged, licensed `.glb` character models here:
- luffy.glb
- naruto.glb
- asta.glb
- gojo.glb
- zoro.glb
- sung-jinwoo.glb

Each model should include a skinned humanoid skeleton, PBR materials, and separately named clips for locomotion and character-specific actions. Recommended clip names are listed in `src/character3d/characterManifest.js`. No model files were supplied with the source projects, so the 3D viewer reports a missing asset instead of showing a sticker as a fake substitute.
